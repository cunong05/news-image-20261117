A newspaper-front-page poster that sums up the world's news of Tuesday, 17 November 2026 in a single 1024×1024 image: the U.S.–Iran strikes, Ukraine's second day of hits on the Kerch Bridge, Nvidia's record $115bn quarter, Trump's trip to the APEC summit in Shenzhen, the four-nation push to open Gaza aid crossings, and the U.S. losing its measles-free status — plus a footer strip with the day's other major stories.

The image is pre-rendered and bundled as `entry.png`; `main.ts` (Node stdlib only, no network) copies it to `/output/entry.png`, so both runs write byte-identical output.

## Run it

```sh
node main.ts
```
